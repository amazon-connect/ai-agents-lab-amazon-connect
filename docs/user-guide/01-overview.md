# Overview

AI Agents Lab for Amazon Connect is a browser-based tool that helps you test, evaluate, and observe the behaviour of Amazon Connect AI Agents. It runs entirely in your browser — there is no backend server and no data is stored outside your AWS account.

## What you can do

The tool covers three areas that feed into each other:

**Observe** — Browse real customer contacts from your Connect instance and inspect exactly what happened inside each AI agent interaction: which model was called, with what prompt, what tools were invoked, how long each step took, and how many tokens were consumed. This is your primary debugging tool — when an agent behaves unexpectedly in production, the span waterfall is where you find out why.

**Test** — Send conversations to your agents manually (chat or voice) or run automated scripts at scale. A single test script can be executed once to verify behaviour, or run hundreds of times in parallel to measure reliability and latency. Voice testing uses real WebRTC — the same audio path your customers use.

**Evaluate** — After running a batch test, measure whether the agent actually did the right thing in each conversation. Not just "did it complete?" but "did it verify the customer's identity, look up the right order, and resolve the issue through the correct steps?" Evaluation uses Amazon Connect's native evaluation capability — you define what good looks like through structured evaluation forms, and Connect's gen-AI automatically scores each contact against those criteria.

## How the pieces connect

The test and evaluate capabilities are designed to flow into each other:

1. Use **Manual Testing (chat)** to have a representative conversation, then export it as a test script and generate an evaluation form from it.
2. Use **Batch Testing** to run that script at scale and export the results.
3. Use **Evaluation** to score those results against the evaluation form.

The **Span Waterfall** stands apart — it works against any contact in your Connect instance, whether from real customers or generated by the testing tool. It's where you go when evaluation flags a problem, or when something unexpected happens in any contact and you need to understand exactly what the agent did.

## What you need before you start

- Access to this application (your administrator will have provided the URL)
- An AWS IAM Identity Center account with permissions for the Connect instance you want to work with
- A Connect instance with at least one AI agent configured

> **Note:** Automated testing (script runner, batch, voice) requires one-time infrastructure setup the first time you use the Testing page with a given Connect instance. This provisions a Lex bot in your AWS account, associates it with the selected Connect instance, and creates a contact flow inside that instance. It takes 1–2 minutes and must be repeated for each Connect instance you work with. See [Infrastructure Setup](./05-infrastructure-setup.md).
